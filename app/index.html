    Setting up the QS

    1. Connect a MIDI cable from your interface's Out to the QS MIDI In. To read names from the QS, also connect the QS MIDI Out to your interface's In.
    2. On the QS press PROGRAM, then GLOBAL, and find the MIDI page: set MIDI Program Select (PrgSl) to On (or to the channel you pick here) and General MIDI to Off. With Program Select off the QS ignores program changes; with General MIDI on it ignores bank changes.
    3. Set the channel here to the QS's Program mode channel (channel 1 unless you changed it).
    4. Close any DAW or other app that has the MIDI ports open. On Windows only one app can use a MIDI port at a time.

    Library patches go to the QS edit buffer only, so your User bank isn't touched until you press STORE on the QS or use "Store to User…" here.

    Patches not changing?

    The test switches programs on the QS, reads back what happened, then returns to the patch you last picked here. It needs the QS MIDI Out connected as well.
